# CuteDart

Mobile virtual darts game. Cute, colorful, GitHub Pages friendly.

## Game modes

### A - Classic Dart
- 301 / 501
- Practice mode
- Touch drag throw
- Dartboard scoring
- Three darts per round
- Bust rule
- 180 statistics
- localStorage records

### B - Camera Dart (B1)
- Rear-camera live background
- Movable virtual dartboard
- Adjustable dartboard size
- Touch throwing directly on the virtual board
- Shared dartboard scoring rules
- No backend required

Camera access requires HTTPS or localhost and browser permission. GitHub Pages provides HTTPS.

Pure HTML, CSS and JavaScript. No backend or external libraries.
